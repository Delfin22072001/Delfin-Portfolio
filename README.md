# Delfin Portfolio

Responsive personal portfolio website built with plain HTML, CSS, and JavaScript. No build step or dependencies required.


## Run locally
1. Extract the folder.
2. Open `index.html` in your browser (or use VS Code Live Server).

## Included sections
- Intro / Open-to-work hero
- About
- Skills
- Projects: TrendHub E-commerce, Vadivam Architects & Builders, Task Manager
- Experience: Vintorix Private Limited
- Contact links

## Before publishing, verify/edit
- Confirm the email in the Contact section (`delfin.dev2207@gmail.com`) is the email you want public.
- Update project links if you have newer live links or repositories.
- Confirm the Vadivam website URL.

## Publish
Can be deployed as a static website on Vercel, Netlify, or GitHub Pages. Upload these files as the project root; no build command is needed.
